# IAYO PRIVATE memory rules

- Explicit owner command "recuerda:" creates a candidate, never silently rewrites validated memory.
- Candidate -> validated is a distinct transition.
- Every memory keeps provenance/source and timestamps.
- Reflections are not facts.
- State is mutable working context, not autobiographical truth.
- Corporate FERVAL information is excluded by default.
- Deletion/forget requests must be auditable and must not be represented as completed until storage confirms it.
